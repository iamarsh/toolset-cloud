# Security Policy

Thank you for helping keep toolset.cloud secure!

If you discover a security vulnerability, please report it to:
- Email: contact@iamarsh.com
- Alternative: contact@iamarsh.com

We take all security reports seriously and will respond within 24 hours.

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes (optional)

We appreciate responsible disclosure and will credit researchers upon request.
